# Pregled i potvrda vesti

Prvi paket: `data/llm/batch-001.json`; predlozi asistenta: `data/llm/predictions-001.json`.
Predlog nije ljudska odluka. Nijedna vest nije unapred potvrđena.

## Otvori pregled

Iz korena projekta:

```powershell
.\.venv\Scripts\python.exe -m petrovaradin_archive.cli relevance page .\data\llm\batch-001.json --out .\data\llm\pregled-001.html
Start-Process .\data\llm\pregled-001.html
```

Za svaku vest pročitaj razlog i dokaz, po potrebi otvori ceo tekst ili izvor.
Izaberi svoju odluku, dopuni razlog i označi potvrdu. Dugme na dnu izvozi samo
označene odluke u JSON u Downloads/preuzimanja. Nepotvrđene vesti ostaju netaknute.
Izbori se pamte u istom pregledaču ako je localStorage dostupan; sačuvaj JSON pre
promene pregledača. Stranica radi bez interneta; izvorni linkovi traže internet.

## Upis u bazu

Pošalji preuzeti fajl u chat radi uvoza, ili sa stvarnom putanjom fajla:

```powershell
.\.venv\Scripts\python.exe -m petrovaradin_archive.cli relevance import-decisions "C:\putanja\odluke-ID.json"
.\.venv\Scripts\python.exe -m petrovaradin_archive.cli relevance import-decisions "C:\putanja\odluke-ID.json" --apply
```

Prva komanda proverava bez upisa odluka; druga ih upisuje zajedno u jednoj transakciji.
Ponovljeni uvoz identičnog fajla ne pravi duplikate. Ako je tekst, status ili ljudska
odluka promenjena od izvoza pregleda, uvoz se prekida. Ponovo generiši pregled.
Za promenu teksta treba i novi batch. Ispravke ostaju u istoriji.

`uncertain` znači dodatni pregled, ne odbacivanje. Takvi zapisi ostaju dostupni u
postojećem pregledu i preko `relevance show ID`; v1 generator narednog paketa ih
ne ponavlja automatski nakon ljudske odluke. Ne koristi `irrelevant` samo zato što
je scraper izdvojio pogrešan tekst. U prvom paketu ima stranica komentara, pretrage
i nepovezanih isečaka: potrebno ih je naknadno obraditi u ekstraktoru.

Posle uvoza potvrda napravi sledeći paket komandom `relevance batch`; potvrđeni
primeri automatski ulaze u prompt. Automatski API pozivi i treniranje nisu uključeni.
Za novi paket predloge ponovo priprema asistent ili odabrani model i uvozi ih kroz
`relevance import`, zatim se generiše novi pregled.
