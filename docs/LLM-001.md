# LLM-001: relevantnost uz ljudsku potvrdu

Prva verzija radi preko JSON paketa, bez API kljuca i automatskih mrežnih poziva.
Model dobija glavni tekst, pravila v1 i poslednjih 30 potvrđenih primera.
Ovo je pamćenje kroz primere u promptu, nije treniranje težina modela.
Izbor komercijalnog ili lokalnog modela ostaje nezavisan od arhive.

## Pokretanje (PowerShell iz korena projekta)

```powershell
.\.venv\Scripts\python.exe -m petrovaradin_archive.cli relevance batch --limit 30 --out .\data\llm\batch-001.json
```

Paket uključuje samo awaiting_review zapise sa postojećim article_text, bez ranijih
ljudskih relevance odluka. Izvori se smenjuju radi raznovrsnosti. Ako nema teksta,
prvo koristiti postojeću komandu `analyze --limit 3000`. Prazan paket ne znači da
više nema URL-ova: neki mogu čekati izdvajanje teksta ili već imati ljudsku odluku.
Paket i dalje može ponoviti nepotvrđene zapise iz prethodnog paketa.

Paket dati LLM-u uz zahtev da sledi instructions i vrati JSON bez Markdown ograde:

```json
{"batch_id":"ID IZ PAKETA","predictions":[{"id":123,"label":"context","reason":"Istorijska veza sa Petrovaradinom","evidence":"DOSLOVAN ODLOMAK IZ TEXT"}]}
```

```powershell
.\.venv\Scripts\python.exe -m petrovaradin_archive.cli relevance import .\data\llm\predictions-001.json --model "ime-koriscenog-modela"
.\.venv\Scripts\python.exe -m petrovaradin_archive.cli relevance show 123
```

Uvoz proverava ID, kategoriju, razlog, doslovnost dokaza i da tekst nije promenjen.
Delimični odgovor je dozvoljen; dupli uvoz istog ID-a iz istog paketa nije.
Uvoz nikad ne menja status vesti. Pregled prikazuje glavni tekst, predloge i istoriju.
Tek nakon eksplicitne odluke korisnika izvršiti, sa stvarnim ID-em i citatom:

```powershell
.\.venv\Scripts\python.exe -m petrovaradin_archive.cli relevance decide 123 context --reason "Istorijska veza" --evidence "DOSLOVAN ODLOMAK IZ TEXT"
```

- `direct` i `context`: archived/approved.
- `irrelevant`: rejected/hidden; sačuvani sadržaj se ne briše.
- `uncertain`: awaiting_review/hidden; ostaje za pojedinačno razmatranje.

Ponovljena decide komanda dodaje ispravku, ne briše istoriju. Postavka javne vidljivosti
izvora ostaje na snazi. Stara komanda `review` ne zapisuje ove primere: u ovom toku
koristiti `relevance decide`. Potvrđena relevantnost nije potvrda istorijske tačnosti.

Odluke, hash teksta, verzija kriterijuma, paketi i model predloga čuvaju se u istoj
SQLite bazi u tabelama relevance_*. Backup baze čuva i ovo pamćenje.
Polazni kriterijum: Petrovaradinska ulica van Petrovaradina, bez druge veze,
nije relevantna; istorijska veza može biti relevantna i kada se vest bavi drugim gradom.
Nijedan konkretan URL nije automatski odobren u ovoj implementaciji.

## Sledeća provera kvaliteta

Ručno oceniti 30–50 raznovrsnih vesti. Odvojiti budući test skup od primera u promptu.
Meriti posebno relevantne vesti koje model pogrešno odbacuje. Automatsko odlučivanje
i direktni API pozivi nisu uključeni u v1.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_relevance.py
```
